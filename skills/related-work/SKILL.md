# Related work drafting

1. Run 2-4 `search_library` calls covering the main sub-areas of the topic (e.g. methods family A, family B, evaluation/analysis).
2. Cluster the relevant papers (relevance >= 0.5) into 2-4 themes.
3. Write one paragraph per theme in formal academic English (unless the user asks otherwise): what the line of work does, representative papers [n], how they differ, and the open gap. Every factual claim about a paper must cite it.
4. End with one sentence positioning the user's work relative to these lines if the user described their work.
5. Never cite papers that are not in the source list.
